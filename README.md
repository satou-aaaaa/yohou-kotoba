# 予報ことばよみ（yohou-kotoba）

「昼過ぎ」は何時から？「一時」と「時々」のちがいは？ 天気予報のことばの意味を選ぶ、1日5問の学習ゲーム。

- 遊ぶ: <https://satou-aaaaa.github.io/yohou-kotoba/>
- 答えは気象庁の資料（「予報用語」の時・降水・風・気温・天気、「雨の強さと降り方」、よくある質問の降水確率）に基づく。
- 町の名前と予報はすべて架空。本当の天気とは関係ない。
- このゲームは気象の公式の情報の代わりではありません。本当の天気予報・警報・注意報は、気象庁の発表で確かめてください。
- 記録は遊ぶ人のブラウザ（localStorage）だけに残り、外へ送らない。外から読むのは文字（Google Fonts）だけ。
- 感想は画面の「感想を送る」から（GitHub の Issue フォーム。名前・メールは要りません）。
